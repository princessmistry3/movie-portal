# Movie Portal

A web application for browsing and discovering movies and series.

## Features
- Browse Movies and Series
- Search Functionality
- Details Page
- Moveies Page
- Series Page
- Recently Viewed
- Contact Page
- Responsive Design
- Mobile-Friendly Sidebar

## Technologies Used
- Nuxt.js
- Vue.js
- Tailwind CSS
- OMDb API
- Iconify
- Local Storage

## Prerequisites
- Node.js (version 18 or higher)

## Setup

Install dependencies:

```bash
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```
